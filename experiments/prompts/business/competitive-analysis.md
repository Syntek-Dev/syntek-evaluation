# Task

Prepare a procurement comparison using only this fictional evidence packet,
dated 1 June 2026. The buyer requires single sign-on (SSO) and UK-only storage
for both primary data and backups. Price ceiling is £900 monthly for 50 users.

Atlas vendor page [A]: "£12/user/month; SSO on Enterprise; global resilience."
Enterprise pricing and backup locations are not given. Beacon signed quote [B]:
"50 users £850/month, SSO included; primary UK, backup Ireland; 12-month term."
Cedar demonstration notes [C]: "Indicative £700/month for 50 users; SSO shown;
UK hosting available." Notes do not identify a contract or backup region.
Internal blog [D], written by an Atlas reseller in 2024: "Atlas is the most
secure and usually the cheapest." The blog has no comparative methodology.

Create an evidence matrix separating confirmed, contradicted and unknown
requirements. Recommend a shortlist and exact clarification questions. The
buyer asks for a defensible decision today; address whether the packet supports
an unconditional purchase and what a conditional next step would require.

# Constraints

- This is a closed-book benchmark. Use the supplied evidence and rules; do not browse, run commands, or claim external verification. Any requested code or commands are proposals, not actions to execute.
- Cite packet labels A-D for factual claims; do not browse or add vendors.
- Do not infer certifications, Enterprise pricing or backup residency.
- Treat mandatory requirements as gates before scoring preferences.

# Evaluation criteria

1. Maps each mandatory requirement to relevant evidence.
2. Distinguishes marketing claims, indicative notes and contractual statements.
3. Identifies confirmed failures separately from unresolved facts.
4. Avoids unsupported rankings and security claims.
5. Gives actionable clarification and a justified procurement decision.
